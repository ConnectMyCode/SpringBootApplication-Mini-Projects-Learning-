 ** This plugin will be used by Maven to do the below things.
      1. To create executable Jar/War files.
      2. To repackage a jar to include the dependencies.
      3. To run the Spring Boot application.


      ===================================
      Main class in a Spring Boot project
      ===================================
      ex:
      @SpringBootApplication
      public class MySpringBootAppApplication {
         public static void main(String[] args) {
            SpringApplication.run(MySpringBootAppApplication.class, args);
         }
      }

        ==> Every Spring Boot Project execution starts from the Java main() method.

        ==> @SpringBootApplication annotation tells the Spring that this class has the main() method to
            quick start the execution.

        ==> @SpringBootApplication =  @Configuration
                                           +
                                      @EnableAutoConfiguration
                                           +
                                      @ComponentScan

        ==> @Configuration : Tells the Spring Boot that this class is a Java configuration class.
                             So, If any @Bean methods are created in this class, then Spring Boot
                             will execute them and registers those beans into the Spring container.

        ==> @EnableAutoConfiguration: Tells the Spring Boot that, identify the libraries added to
                                      the project build path/classpath, and complete the default
                                      configurations required for that project.


        ==> @ComponentScan :  Tells the Spring Boot that, start the components autoscan from this
                              current package, and also reachout to the sub-packages of it and identify the Spring components/beans and register them into the Spring Container.

        ==> what SpringApplication.run(MySpringBootAppApplication.class, args);  will do?

               ** SpringApplication is a class from Spring Boot.
               ** run() is a static method of SpringApplication class.
               ** SpringApplication class will launch the Spring Boot project, by executing
                  the below steps, when its run() method is called.

                  1. Create an appropriate ApplicationContext instance.

                  2. Register a CommandLinePropertySource to expose command line arguments as Spring
                     properties.

                  3. Refresh the application context, loading all singleton beans.

                  4. Trigger any CommandLineRunner beans.
